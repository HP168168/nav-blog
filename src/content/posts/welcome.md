# 欢迎使用你的全新个人导航博客！

这是一个基于 **Astro** 与 **Keystatic** 构建的现代化站点。

### 🌟 核心特色：
1. **纯静态生成（SSG）**：秒开、极致 SEO，可免费托管在 Cloudflare Pages、Vercel 或 GitHub Pages。
2. **可视化管理后台**：访问 `/keystatic` 即可进入管理面板，无需手动修改代码。
3. **二合一架构**：
   - 首页是高颜值的分类网址导航；
   - 博客栏目支持 Markdown 写作与排版。

祝你使用愉快！
